# プロジェクト構成と実装計画

## フォルダ構成

```text
Assets/
  RuruneMVP/
    Scripts/       カメラ、モーション、表情、操作UI
    Editor/        シーン生成、BlendShape選択Inspector
    Scenes/        モデルを含まない初期シーンの保存先
    Animations/    自作・再配布可能なController等の保存先
    Prefabs/       自作・再配布可能なPrefabの保存先
  LocalOnly/       購入モデル・購入モーション・ローカルシーン（Git除外）
Docs/
```

このリポジトリは導入用ソースです。バージョン確認後にローカルで Unity プロジェクトを作り、
Assets/RuruneMVP をコピーします。モデル名、階層、表情名はコードに埋め込みません。
.meta は Unity に生成させます。既存ファイルを更新するときは既存 .meta を保持してください。

## 第1段階：今回のMVP

1. 独立した Transform を注視する OrbitCamera を実装。
2. 実際の Animator を参照し、登録ステートの存在を確認して CrossFadeInFixedTime で切り替える。
3. SkinnedMeshRenderer ごとに実在する名前を選んで表情を登録。切り替え時に前の表情の制御値を復元。
4. IMGUI のスクロール可能な操作パネルから呼び出す。UI 上ではカメラ入力を抑止。
5. モデルを含まないシーン生成機能、Editor 設定手順、受け入れチェックリストを作成。

データは Inspector でシーンに保存します。表情は複数 Renderer に対応し、無効な設定は適用前に拒否します。
表情適用中は登録したチャンネルを LateUpdate で保持します。VRChat の FX、独自の瞬き、
リップシンク等との統合は未実装であり、同じチャンネルを制御するコンポーネントとは競合し得ます。

## 後続段階（未実装）

- 第2段階：クリック判定、ドラッグ、反応アニメーション。モデルのコライダーと操作範囲を設計。
- 第3段階：室内シーンとキャラクター移動。移動方式・衝突・アニメーション連携を決定。
- 第4段階：Windows デスクトップマスコット。透過、最前面、クリック透過、DPI を検証。
- 第5段階：AI テキスト会話、音声認識・合成。サービス選定、認証、音声と表情の同期を設計。

各段階は前段階の手動検証完了後に追加します。
